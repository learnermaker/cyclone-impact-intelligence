## Important Temporal Notes

### GPM IMERG (Apr 30–May 4, 2019)

The GPM product covers a 96-hour window that **crosses the T-24h prediction
cutoff (2019-05-02T05:00:00Z)**. It is a **post-event historical observation**,
not a pre-event forecast rainfall. It is correctly marked:

```
predictionSafe: false
revealOnly: true
temporalRole: "event_observation"
```

Do NOT use this dataset for T-24h prediction rainfall. It feeds only replay
evaluation (after the explicit REVEAL step).

### Sentinel-1 (May 4–10, 2019)

Sentinel-1 GRD SAR backscatter change detection is used as an **inundation
proxy**, not exact flood-depth ground truth. The flooded fraction per H3 cell
reflects SAR signal change that is consistent with inundation, but can include
non-flood signals (urban bright targets, wind roughening, etc.). Always cite as
"observed inundation proxy" not "flood ground truth".

## Synthetic Demo Fixture

The primary demo path uses a synthetic fixture generated by
`pnpm generate:fixture`:

| File | Description |
|------|-------------|
| `data/fixtures/fani-demo/cells.geojson` | 43,009 H3 res-8 cells with synthetic hazard/exposure |
| `data/fixtures/fani-demo/hazard_scenario.json` | T-24h HazardScenario from IMD documented parameters |
| `data/fixtures/fani-demo/infrastructure.json` | 15 curated infrastructure assets (approximate locations) |
| `data/fixtures/fani-demo/metadata.json` | DemoFixtureMetadata with evaluation firewall |

All synthetic files carry `dataStatus: "DEMO_FIXTURE"`. The Zod schema and
TemporalFirewall enforce that synthetic data cannot produce claimed historical
accuracy metrics.

## GEE Pipeline Scripts

Located in `pipelines/gee/`:

```
01_worldpop_h3_sample.py   — WorldPop 2019 population sampling
02_nasadem_h3_sample.py    — NASADEM elevation sampling
03_gpm_imerg_fani.py       — GPM IMERG Fani event rainfall
04_sentinel1_flood_actual.py — Sentinel-1 post-event flood proxy
```

All scripts require an authenticated GEE project (set `project = "your-project-id"`)
and export to `data/processed/` or `data/historical/fani/actual/`.

## Infrastructure Fixture

The infrastructure fixture (`data/fixtures/fani-demo/infrastructure.json`)
contains **15 curated assets** with approximate coordinates from public/OSM
references. It is labelled as:

```
"locationStatus": "APPROXIMATE — coordinates are public knowledge approximations, not surveyed points"
```

The inventory is explicitly incomplete. It covers: hospitals, emergency shelters,
bridges, power infrastructure, and water supply points in the Puri/Khurda coastal
corridor. **Do not present this as a complete OSM extraction.**

Wording to use in the UI: *"Curated critical infrastructure inventory based on
public/OSM references. Inventory incomplete."*

## Re-running GEE Pipelines

To regenerate the processed data products:

```bash
# Authenticate first
earthengine authenticate

# Run each pipeline
python pipelines/gee/01_worldpop_h3_sample.py
python pipelines/gee/02_nasadem_h3_sample.py
python pipelines/gee/03_gpm_imerg_fani.py
python pipelines/gee/04_sentinel1_flood_actual.py
```

After re-running, clear the in-memory cache:
```typescript
import { clearGEECache } from "./src/engine/loader/gee-loader";
clearGEECache();
```
